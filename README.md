# pydata-helsinki.github.io

Source for the [PyData Helsinki](https://pydata-helsinki.github.io/) site.

The site is generated by `build.py`, a small custom builder:
one YAML file per event in `events/` renders into

- the index page (upcoming/past listings; old `#YYYY-MM-DD` anchors preserved),
  with Organization + WebSite JSON-LD
- a page per event at `/events/<slug>/` with [schema.org Event](https://schema.org/Event)
  JSON-LD: offers, sponsor, performers, and each talk as a `subEvent` with its
  video. Structured data is deliberately maximalist — it serves not just
  Google's event search but any AI system parsing the pages.
- `events.ics` — subscribable iCalendar feed
- `feed.xml` (Atom) and `events.json` (JSON Feed)
- `sitemap.xml` (referenced from `robots.txt`, which allows all crawlers)

Everything listed in `STATIC` in `build.py` (assets, slides, for-speakers,
for-companies, style.css) is copied through unchanged.

## Adding an event

```
just new-event 2026-09-15-acme
```

creates a skeleton `events/2026-09-15-acme.yaml` with the start date filled in
from the slug (the filename becomes the URL slug). Then edit. Full example:

```yaml
title: Meetup at Acme
start: 2026-09-15 17:30
end: 2026-09-15 20:30
venue:
  name: Acme
  address: Katukatu 1        # street address helps event SEO, add when known
registration:
  url: https://www.meetup.com/pydatahelsinki/events/123456789/
  platform: Meetup           # or Luma, pretix, ...
  # opens: 2026-09-01        # optional, only while url is absent
talks:                       # optional, add as the programme firms up
  - speaker: Ada Lovelace
    speaker_url: https://example.com
    title: Notes on the Analytical Engine
    lightning: true          # optional
    video: https://youtu.be/…  # optional, add after the recording is up
```

**RSVPs not open yet?** Just leave `registration:` out (or url-less). The
event page then says "Registration is not open yet" and points at the feeds,
and the JSON-LD offer gets `availability: PreSale` (plus `validFrom` if you
set `registration.opens`). Adding the `url` later flips everything to open.

**Sponsors**: for a normal meetup the hosting venue is credited as sponsor
automatically (any event with talks). Add an explicit `sponsor: {name, url}`
only when they differ — e.g. Cactos sponsored but rented Sofia as the venue.
Pub nights and picnics (no talks) get no sponsor.

Commit to `main` and GitHub Actions builds and deploys. A daily scheduled
build moves events from "upcoming" to "past" without needing a commit.

## Building locally

```
just build
uv run -m http.server -d _site
```
